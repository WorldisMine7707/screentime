# ScreenTime APK — 5 Steps mein Download Karo (FREE)

## Kya hoga: GitHub automatically APK build karega, aap download karoge

---

## STEP 1 — GitHub Account Banao (FREE)

1. Browser mein jao: **github.com**
2. "Sign up" click karo
3. Email, username, password bharo
4. Account verify karo

---

## STEP 2 — New Repository Banao

1. Login ke baad, upar **"+"** button click karo
2. **"New repository"** click karo
3. Name: `screentime-dajiraj`
4. **"Public"** select karo
5. **"Create repository"** click karo

---

## STEP 3 — Files Upload Karo

1. Repository page pe **"uploading an existing file"** link click karo
2. **ScreenTimeApp.zip extract karo** (ScreenTimeApp folder milega)
3. Us folder ke **andar ke saare files** ek ek karke upload karo:
   - `.github/` folder (yahi APK build karta hai!)
   - `app/` folder
   - `build.gradle`
   - `settings.gradle`
   - `gradle.properties`
   - `gradlew`
   - `gradle/` folder

   **TIP:** Saare files ek saath drag & drop kar sakte ho!

4. Neeche **"Commit changes"** click karo

---

## STEP 4 — APK Build Hone Do (5-7 minutes)

1. Repository mein upar **"Actions"** tab click karo
2. **"Build APK"** workflow dikh raha hoga — running hoga (yellow circle)
3. Wait karo jab tak **green checkmark** ✅ nahi aata
4. Agar red ❌ aaye — mujhe screenshot bhejo, fix kar dunga

---

## STEP 5 — APK Download Karo

1. Green checkmark pe click karo
2. **"ScreenTime-Dajiraj-APK"** pe click karo
3. **APK file download** ho jaayegi!

---

## PHONE PE INSTALL KARO

### Samsung M16 pe:

1. **Settings → Security → Unknown Sources → ON** karo
   (Ya: Settings → Apps → Special App Access → Install Unknown Apps → Browser → Allow)

2. Downloaded APK file open karo (Files app mein)

3. **"Install"** tap karo

4. App install ho jaayega!

### Pehli Baar Kholne Pe:
- **"Usage Access"** permission do:
  Settings → Apps → Special app access → Usage Access → ScreenTime → ON

- **"Battery"** permission: 
  Settings → Apps → ScreenTime → Battery → Unrestricted
